# Solar System

Explore an interactive 3D solar system in your browser.

**[Open the live demo](https://rhande427-oss.github.io/Solar-System/)**

## Features

- Select planets to view information
- Toggle orbital paths and labels
- Adjust animation speed, pause, and reset the view
- Drag to rotate and scroll to zoom
- Responsive layout for desktop and mobile

## Run locally

Open `index.html` in a modern browser.

## Built with

HTML, CSS, and JavaScript.
